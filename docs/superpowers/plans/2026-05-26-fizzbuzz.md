# FizzBuzz Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a FizzBuzz page where the user enters a number, the frontend POSTs it to Spring Boot, and the backend returns the FizzBuzz result computed by a pure function.

**Architecture:** Spring Modulith `fizzbuzz` package — `FizzBuzz.java` is a pure static function (functional core), `FizzBuzzController` handles HTTP and calls it (imperative shell). Frontend uses React Router with `App.tsx` as landing page and `FizzBuzzPage` as the feature page; Vite proxy forwards `/api` to `:8080`.

**Tech Stack:** React 19 + TypeScript + Vite + Tailwind + DaisyUI + React Router DOM / Spring Boot 4 + Java 25 + Spring Modulith + Lombok / JUnit 5 + AssertJ + JsonUnit (backend) / Vitest + Testing Library (frontend)

```java
class FizzBuzz {

        if (n % 15 == 0) return "FizzBuzz";
        if (n % 3 == 0) return "Fizz";
```

```tsx
import { useState } from 'react'

export default function FizzBuzzPage() {
  const [input, setInput] = useState('')
  const [result, setResult] = useState<string | null>(null)
  const [error, setError] = useState<string | null>(null)

  async function handleSubmit(e: React.FormEvent) {
    e.preventDefault()
    setResult(null)
    setError(null)

    const response = await fetch('/api/fizzbuzz', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ n: Number(input) }),
    })

    const data = await response.json()
    if (response.ok) {
      setResult(data.result)
    } else {
      setError(data.detail ?? 'Something went wrong')
    }
  }

  return (
    <main className="flex flex-col items-center gap-6 p-8">
      <h1 className="text-3xl font-bold">FizzBuzz</h1>
      <form onSubmit={handleSubmit} className="flex gap-2">
        <input
          type="number"
          value={input}
          onChange={e => setInput(e.target.value)}
          placeholder="Enter a number"
          className="input input-bordered"
        />
        <button type="submit" className="btn btn-primary">
          Check
        </button>
      </form>
      {result !== null && (
        <p role="status" className="text-2xl font-semibold">
          {result}
        </p>
      )}
      {error !== null && (
        <p role="alert" className="text-error">
          {error}
        </p>
      )}
    </main>
  )
}
```
