# ADR-000: Adopt Organization Standard Technology Stack

## Status

Accepted

## Context

The organization standardizes core application technologies to:

* simplify operations
* reduce maintenance complexity
* improve knowledge sharing between teams
* align deployment and infrastructure practices

The approved technology stack includes:

* Spring Boot for backend services
* PostgreSQL for relational database
* Docker for containerization
* React for frontend applications

This project follows the organization technology standards.

## Decision

Adopt the organization standard technology stack:

* Backend: Spring Boot
* Database: PostgreSQL
* Container Platform: Docker
* Frontend: React

Project-specific architectural decisions will be documented in separate ADRs.

## Consequences

### Positive

* Consistent engineering practices across teams
* Easier onboarding and support
* Shared infrastructure and deployment patterns
* Better internal knowledge reuse

### Negative

* Reduced flexibility in technology selection
* Some technologies may not be optimal for every use case
